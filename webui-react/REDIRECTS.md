# React Redirect Matrix

React is mounted at `/app/` while the Angular UI remains mounted at `/webui/`.
These mappings describe legacy Angular URL shapes and their React equivalents.

## Route Matrix

| Legacy Angular URL                                                      | React `/app` equivalent            | Behavior                                                                                                                        |
| ----------------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `/webui/torrents?<search params>`                                       | `/app/?<normalized search params>` | `/app/torrents?<search params>` is accepted as a legacy alias and replace-redirects to `/app/` with validated search params.    |
| `/webui/torrents?torrent=<40-hex>&tab=<files\|tags\|reprocess\|delete>` | `/app/torrents/<infoHash>`         | The `torrent` hash opens the full React detail route. Other search params and `tab` are dropped. Detail tabs are P1b/P1c scope. |
| `/webui/torrents?torrent=<malformed>&tab=<any>&<search params>`         | `/app/?<normalized search params>` | Malformed `torrent` and `tab` are stripped; valid search params are preserved.                                                  |
| `/webui/torrents/permalink/:infoHash`                                   | `/app/torrents/:infoHash`          | `/app/torrents/permalink/:infoHash` is accepted and replace-redirects to the React detail route.                                |
| `/webui/dashboard`                                                      | `/app/dashboard`                   | React P1a provides the dashboard stub at `/app/dashboard`.                                                                      |
| `/webui/dashboard/...`                                                  | `/app/dashboard/...`               | Reserved for P2 dashboard parity routes. P1a only implements the `/app/dashboard` stub.                                         |

## Search Params

| Legacy param                | React param                 | Notes                                                                                                                                                                                                                                       |
| --------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `query`                     | `query`                     | String search query; decoded and trimmed.                                                                                                                                                                                                   |
| `content_type`              | `content_type`              | Valid values: `audiobook`, `comic`, `ebook`, `game`, `movie`, `music`, `software`, `tv_show`, `xxx`, `null`.                                                                                                                                |
| `order`                     | `order`                     | Valid values: `relevance`, `name`, `published_at`, `updated_at`, `size`, `files_count`, `seeders`, `leechers`. `relevance` is valid only when `query` is non-empty.                                                                         |
| `desc`                      | `desc`                      | `1` is descending, `0` is ascending. Default ordering is elided.                                                                                                                                                                            |
| `page`                      | `page`                      | Positive integer; defaults to `1` and is elided.                                                                                                                                                                                            |
| `limit`                     | `limit`                     | Positive integer; defaults to `20` and is elided.                                                                                                                                                                                           |
| `min_size`, `min_size_unit` | `min_size`, `min_size_unit` | Size unit defaults to `MiB`; allowed units: `KB`, `MB`, `GB`, `TB`, `KiB`, `MiB`, `GiB`, `TiB`.                                                                                                                                             |
| `max_size`, `max_size_unit` | `max_size`, `max_size_unit` | Same unit rules as `min_size`.                                                                                                                                                                                                              |
| `published_at`              | `published_at`              | Valid backend time-frame strings are preserved: relative `\d+[smhdwMy]`, named frames (`today`, `yesterday`, `this week`, `last week`, `this month`, `last month`, `this year`, `last year`), single dates, and `start to end` date ranges. |
| `torrent_source`            | `torrent_source`            | Comma-separated selected facet values.                                                                                                                                                                                                      |
| `torrent_tag`               | `torrent_tag`               | Comma-separated selected facet values.                                                                                                                                                                                                      |
| `file_type`                 | `file_type`                 | Comma-separated values from the GraphQL `FileType` enum.                                                                                                                                                                                    |
| `language`                  | `language`                  | Comma-separated ISO language values accepted by the GraphQL schema.                                                                                                                                                                         |
| `genre`                     | `genre`                     | Comma-separated selected facet values; preserved only for `movie` and `tv_show`.                                                                                                                                                            |
| `video_resolution`          | `video_resolution`          | Comma-separated values from the GraphQL `VideoResolution` enum plus `null`; preserved only for `movie`, `tv_show`, and `xxx`.                                                                                                               |
| `video_source`              | `video_source`              | Comma-separated values from the GraphQL `VideoSource` enum plus `null`; preserved only for `movie`, `tv_show`, and `xxx`.                                                                                                                   |
| `torrent`                   | route path                  | Valid 40-hex values redirect to `/app/torrents/<infoHash>`; malformed values are stripped.                                                                                                                                                  |
| `tab`                       | dropped                     | Detail tabs are deferred to P1b/P1c.                                                                                                                                                                                                        |
| `facets`                    | dropped                     | Waiver from `docs/react_frontend.md` §1: active panel open/closed state is ephemeral in React. Selected filter values still round-trip through the facet params above.                                                                      |

Waiver from `docs/react_frontend.md` §1: Angular pre-checks all facet
checkboxes when nothing is selected; React leaves them unchecked.
